# Social Media - Java

This is the **Java** implementation of the Social Media sample application, built with **Spring Boot** and the **AWS SDK for Java v2**. It provides two interchangeable repository implementations (a low-level and a high-level async client), backed by the same DynamoDB tables and selectable at application startup. For the full description of the use case, DynamoDB design rationale, and API endpoints, see the [parent README](../README.md).
