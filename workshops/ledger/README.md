# Ledger: Financial Data Modeling with DynamoDB

## Contents
Here you will find scripts for modeling and measuring potential database solutions when modeling financial data in DynamoDB.

## Instructions
This project accompanies the AWS re:Invent 2026 builder workshop: 

- **[DAT415 - Financial Data Modeling with DynamoDB](https://studio.us-east-1.prod.workshops.aws/workshops/5520bbb0-d615-4c91-b94b-93e422083d9f#builds)**  Designing business applications for low latency, high throughput, high consistency, and high availability presents unique challenges at scale. In this session, learn how to model business entities including accounts, journals, and ledgers using Amazon DynamoDB to support workflows that process millions of requests per second. Explore distributed computing patterns that leverage multi-Region replication features in DynamoDB.
